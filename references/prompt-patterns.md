# 提示词结构

只在生成新封面或定向修正时读取。

## 首次生成

提示词必须明确：

1. `原生 3:4 竖版抖音封面，从空白画布构图，禁止裁剪已有图片`。
2. 人物参考图只用于身份一致性；描述人物在画面中的位置、动作、占比和目光方向。
3. 视觉家族、真实场景或 3D 隐喻、前中后景关系和标题安全区。
4. 逐字文字：`主标题「...」`、`副标题「...」`、`系列「...」`、`期数「...」`；没有的字段不生成。
5. `除指定文字外不出现任何其他文字、数字、品牌、水印或伪界面文案`。
6. 手机缩略图下人物和主标题仍清楚，手指与四肢自然。

不要用参考封面作为待编辑底图；它只能用于理解视觉语言。

## 定向修正

一次只修一个已观察到的问题，并明确保留项。例如：

```text
仅修正主标题，把错误文字替换为逐字的「Skill 到底是什么」。
保持人物身份、姿势、背景、构图、灯光、配色和其他文字完全不变。
画布仍为原生 3:4，不裁剪、不扩边，不新增任何文字或水印。
```

若问题涉及整体比例或构图，不做局部补边，重新生成一张原生 3:4 版本。

## 验收顺序

1. 标题逐字一致。
2. 人物身份、五官和年龄感稳定。
3. 手部、肢体和视线自然。
4. 无多余文字、水印或乱码。
5. 人物突出，标题缩略图可读。
6. 原图比例接近 3:4。
