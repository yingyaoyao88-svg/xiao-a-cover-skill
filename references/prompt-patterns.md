# 生图指令

输入图角色必须清楚：使用者自己的三视图是人物身份和服装参考；公开展示图只用于说明构图，不是默认身份来源。生图时使用用户三视图和所选样式的文字描述，不把作者展示人像当作用户参考传入。

```text
原生 3:4 竖版抖音封面，从空白画布生成。
输入的三视图是同一位用户指定人物的正面、侧面和背面。严格保持其可见面容、发型、妆容、衣服、配饰和自然年龄感，不换成其他人的脸；人物为真实摄影，半身出镜。
采用用户选定的样式「样式 ID 与名称」，逐项描述该样式的人物位置、视角、动作、交互接触点和演示成果，具体依 references/styles.md。
共同要求：真人身份与文案一致、手机缩略图下清楚。具体色板、明暗、字形、标题位置、设备数量、人物动作和视角都按所选样式决定：A 暖白黑橙、B 暗紫电影、C 薄荷绿极简、D 酒红复古拼贴。不把四种方案统一为暖白工作室。
主标题「当前标题」；副标题「当前副标题」。没有相应字段时不生成。
除指定文字外不出现其它文字、水印或密集伪界面文案。标题大小写逐字保持，手部与肢体自然，不盖脸。
完整原生 3:4 构图，不裁剪、不扩边，便于整图导出 1080×1440。
```

有用户明确提供的系列名、期数时增加对应逐字文字；不要从三视图或旧样例里继承旧标题。单一问题最多定向修正两次，保留已经正确的人物和布局。

多图对比时统一人物和主副标，各张分别编写独立的风格、排版、色调和动作；可将主标题放上方、底部、侧栏或撕纸字带，但文字逐字保持。不能只改变字体、笔触或卡片材质。
