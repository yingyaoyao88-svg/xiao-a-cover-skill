# 视觉系统

只在选择风格、响应“换风格”或检查连续封面重复度时读取。

## 五类视觉家族

| 家族 | 适合主题 | 构图与画面语言 |
| --- | --- | --- |
| 暖白生活工作室 | 入门、界面认知、个人经验 | 暖白环境光，人物占画面 45%–60%，真实桌面或工作区，留出大标题区；禁止香槟金和泛黄滤镜 |
| 立体软件模块 | Skill、插件、安装、功能拆解 | 3D 卡片、浮动模块、清晰层级，人物与核心模块形成前后景 |
| 复古信息图 | 自动化、流程、时间、法则 | 奶油纸张、番茄红或橙棕点色、时钟/流程箭头/清单，避免蓝色科技底 |
| 暗色科技资讯 | 模型能力、行业变化、产品升级 | 深灰黑环境、高对比边缘光、少量高饱和点色，人物轮廓必须清晰 |
| 编辑拼贴 | 观点、对比、避坑、案例复盘 | 大字、纸张切片、照片框、标注符号，多信息层级但不拥挤 |

## 自动选型

- “界面、入门、第一次、教程”优先暖白生活工作室。
- “Skill、插件、安装、功能”优先立体软件模块。
- “自动化、按时、步骤、法则、清单”优先复古信息图。
- “升级、发布、模型、行业、重磅”优先暗色科技资讯。
- “区别、误区、避坑、案例、复盘”优先编辑拼贴。

若多类都适用，选择最近三个 `cover-meta.json` 中未使用的家族。

## 换风格

“换风格”至少更换以下五项中的三项：

1. 版式骨架。
2. 人物位置或朝向。
3. 场景语言。
4. 字体体系与标题形态。
5. 色彩结构。

只换背景色不算换风格。保持人物身份、系列识别和 3:4 规格不变。
