# 人物导入与样式选择

## 本地状态

从用户主目录解析 `~/.agents/xiao-a-cover/active-profile.json`，该文件位于技能仓库之外。不要从其他用户、作者示例或随机磁盘目录发现并借用人物。

本地配置至少记录：人物 ID、正侧背参考图路径（一个合成图或三张图）、`referenceScope`（`half-body` 或 `full-body`）、用户认可的服装/配饰描述、`styleId`（A/B/C/D 或尚未选择）、`styleCatalogVersion: 2`、导入日期。只在本地记录绝对参考路径。新 ID 目录已存在时用版本后缀，保留旧人物。旧配置没有此样式版本时，保留有效三视图并重新选择新版样式，不重复要求上传。

本地没有有效配置、图片缺失或用户明确换人时，进入下面两步。用户单条消息中已上传有效三视图并选择样式时，按顺序校验后直接继续。

## 第一步：上传自己的三视图

向用户说明：

> 请先上传你的人物三视图：同一个人的正面、侧面、背面，可以合在一张图里，也可以上传三张。半身封面可用清晰半身三视图，尽量保持相同发型、衣服和拍摄尺度。

等待上传，不提前生成封面或用作者人物占位。收到后检查视角齐全、同一身份、脸部清楚、服装一致。只有单张正脸时说明还缺哪些视角；若用户要求协助制作三视图，可调用可用的生图能力，未观察角度按补全处理，经用户确认后再导入。

有效三视图复制到仓库外的 `~/.agents/xiao-a-cover/profiles/<id>/`，或用户指定的外部人物目录。只保存用户本次选择的三视图，不自动保存原视频与其它照片；不覆盖已有文件。

## 第二步：选择喜欢的样式

确认人物导入完成后，再提供四项选择：

- A 触控大屏：人物在左侧，指尖接触透明大屏，任务流程从接触点展开。
- B 手托成果：人物居中，掌心近景托起文档、图表和成果模块。
- C 桌面指挥台：俯视工作台，人物实际操作键盘与触控板，成果沿桌面展开。
- D 跨屏拖拽：人物拿平板并捏住成果卡，向前景手机拖拽传递。

展示 `docs/showcase/README.md` 中的对应四张效果图（从 Skill 根目录解析），并等待选择。说明展示图的人物只是作者示范，实际生成必须换成使用者上传的三视图。不能因为用户只给标题就自动选择 A；首次风格选择是用户要求的初始化环节。用户明确要求四种都生成时，分别生成四张，不再次要求选唯一选项。

将选择写入本地人物配置。其后同一人物可沿用，用户说“换样式”时再次展示菜单；不要为了每张封面重复要求上传或重新选择。

## 人物一致性

按使用者三视图锁定面容、发型、妆容、衣服与配饰；封面姿态按样式设置为触控、手托、实际操作或跨屏拖拽，不能四张都使用同一个指向加轻托动作。半身参考只生成半身，不自动编造下装和鞋。三视图本身不清楚的细节不要强行固化为特征。
