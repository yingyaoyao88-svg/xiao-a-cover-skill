# 四种不同风格、排版与色调

样式目录版本：3。四种方案对应 docs/showcase 中的新版成品。

## 共同要求

保持同一用户人物身份、发型、服装和配饰；文案逐字一致；原生 3:4、1080×1440 PNG；文字在手机缩略图下清楚，真人不漫画化。

共同框架是人物 IP 与清晰的内容层级，不是统一颜色、标题位置或左右布局。四张同时对比时，使用独立的色板、明暗、字形、标题位置、镜头与动作。界面用图形和图标展示主题，不生成密集伪文字。

## A · 暖白黑橙科技

- **色板与材质**：暖白、黑、鲜橙，明亮中性柔光，透明面板和简洁真实工作台。
- **风格**：瑞士式平面科技编辑排版，清爽网格感和克制细线，避免厚白描边、手刷纸条、立体挤压大字。
- **排版**：主标题左上两行，首行黑、重点词橙；副标小一阶直接对齐其下。
- **人物与动作**：右侧近景真人，食指触碰左中透明任务图标；任务或成果从指尖触点分支展开，另一手自然靠近桌面。
- **验收**：触点与指尖对齐，图标分支清楚，脸部不被文字或面板遮挡。
- **示例**：docs/showcase/codex-touch-screen.png。

## B · 暗紫电影质感

- **色板与光线**：深紫黑背景、洋红与紫白光效，自然肤色主光加紫色边缘光，不沿用橙色或暖白工作室。
- **风格**：电影式人像与玻璃质感成果，空间深度和少量光轨；不要让紫光涂满脸部。
- **排版**：人物居中上部，双手与成果位于画面中段；大标题放在底部约 68%–94%，首行白、次行浅紫，略带未来感斜体与克制立体边；副标位于顶部安全区。
- **人物与动作**：双手控制或托住一份发光成果，少量图文模块围绕中心成果展开；不放木桌和成套电脑手机。
- **验收**：人物身份清楚，脸、手、成果、底部标题分区，不把标题重新放回顶部。
- **示例**：docs/showcase/codex-result-in-hand.png。

## C · 薄荷绿极简

- **色板与材质**：薄荷白、鼠尾草绿、深森林绿，少量柑橘绿点色；哑光白桌、纸卡和自然植物，不沿用黑橙或紫色霓虹。
- **风格**：清新极简生活方式摄影，漫射日光、留白，柔和圆角字形与清晰字距。
- **排版**：标题在左侧分三行，例如 codex / 实战 / 落地用法，采用深绿平面字；副标置于右下白色小标签，不做顶部大横幅。
- **人物与动作**：略俯视构图，人物位于右上或右侧，双手实际操作左下笔记本；任务卡与成果卡以实物形式沿桌面透视排列。
- **验收**：手落在键盘/触控板上，桌面卡片有合理软阴影，无发光全息特效，人物与左侧文字都有留白。
- **示例**：docs/showcase/codex-command-desk.png。

## D · 酒红复古拼贴

- **色板与材质**：酒红、奶油白、珊瑚红、少量炭黑印色；撕纸、胶带和油墨纹理，不沿用现代暖白工作室。
- **风格**：独立杂志式拼贴海报，真人以摄影剪贴呈现；半调与旧纸纹理主要作用于背景和字带，脸部仍保持真实清楚。
- **排版**：真人居左上，右上大号衬线 codex 与复古中文实战形成字阶；落地用法放在底部奶油白斜向撕纸字带，副标位于右中纸签。按完整阅读顺序保留用户全部标题，不添加其它口号。
- **人物与动作**：一手持平板，另一手越过撕纸边界捏住成果卡，形成真实遮挡和接触，画面不重复电脑手机工作室布局。
- **验收**：指尖捏住卡片而非悬空指向；撕纸边缘、卡片与手部的层次准确，脸不做漫画化或印刷变形。
- **示例**：docs/showcase/codex-cross-screen-drag.png。

## 同时生成四张时

只统一人物、文案、尺寸和基本可读性，各张分别编写独立的风格、排版、色调与动作。验收时比较：明暗是否有区别，标题是否都放在同一个位置，字体是否全部相同，人物和设备布局是否重复。不能四张仅换背景颜色，也不能以同一套暖白黑橙大字模板解释所有样式。

元数据记录 styleId、styleCatalogVersion: 3、palette、layout 和实际互动方式。用户明确另行指定的风格或配色优先。
